# Plataforma VTC local: implementación inmediata

**Objetivo:** aplicación de estudio funcional con control libre del usuario. La petición actual autoriza implementación directa; se aplazan animaciones, mascota y pistas.

**Arquitectura:** interfaz modular sin dependencias de instalación, servidor estático Node y progreso en IndexedDB. Ruling: sustituir React/Vite/Dexie por módulos JavaScript y APIs nativas para arrancar sin descargas (la consulta npm no responde). No hay repositorio Git existente; se trabaja en la carpeta indicada por el usuario.

**Especificación:** `temas/especificaciones_del_proyecto_vtc_web_claude_md.md` y aclaraciones de esta conversación.

- [x] Extraer las ocho fuentes PDF con número, página, cuatro opciones y clave; exigir coincidencia entre preguntas detectadas y respuestas.
- [x] Probar y construir selección equilibrada, menor exposición, dificultad personal, barajado por ID, puntuación por módulo y validación de copias.
- [x] Crear inicio, temario, banco consultable, cinco apartados de tests, cuatro ejemplos, estudio/examen, temporizador, navegación libre, marcado, pausa/reanudación e historial.
- [x] Persistir intentos y progreso; permitir copias, restauración y reinicio confirmado, sin bloquear módulos por nivel.
- [x] Añadir explicaciones didácticas, teoría y preguntas EXTRA claramente separadas.
- [x] Comprobar importación, tests Node y flujo real en navegador (escritorio/móvil); dejar servidor abierto.

**Comprobaciones críticas:** un módulo suspenso impide APTO; un cambio de orden no cambia la solución; entregar dos veces no duplica estadísticas; recargar no reinicia el reloj; una copia inválida no reemplaza los datos.
